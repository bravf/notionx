# 拾页 · NotionX

面向个人使用的笔记与结构化数据库应用。支持桌面和手机，内容持久化到服务端 SQLite。

## 启动

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

默认地址为 `http://localhost:5173`。开发服务绑定 `0.0.0.0`，手机与电脑处在同一局域网时，使用 `http://电脑的局域网IP:5173` 访问。手机的 localhost 指向手机自己。系统防火墙需要允许访问此端口。

生产环境：

```sh
npm run build
APP_PASSWORD='设置你自己的密码' npm start
```

长期部署建议使用 HTTPS 反向代理。HTTPS 下设置 `COOKIE_SECURE=true`。PWA 安装和 Service Worker 需要安全上下文，手机普通局域网 HTTP 可直接浏览使用，无法保证可安装为 PWA。

## 功能

- 页面树、收藏、最近访问、拖动排序、子页面、复制、移动、回收站及全局内容搜索。文字内部跨段拖选保留精确文本范围，左侧空白 gutter 拖选整块；Esc 从文字编辑切换到块选择，Shift+方向键扩选或收缩，列表按最近层级处理。支持整块复制、剪切、删除、撤销，Ctrl/Cmd+A 先选当前块、再次全选，Ctrl/Cmd+D 复制所选块。搜索结果可用方向键选择、Enter 打开，并可直接跳到匹配的数据库记录；侧栏页面双击或在菜单中选择“重命名”即可就地改名。
- Tiptap 块编辑器：`/` 菜单、Markdown 快捷输入、标题、列表、待办、引用、提示块、代码、图片（支持粘贴和拖入）、分割线、普通表格和数据库嵌入。左侧手柄在正文和空白 gutter 中都可唤出，菜单支持“转换为”其他块类型。
- 文本加粗、斜体、删除线、链接、撤销重做；桌面拖动块（完整排版随指针移动、相邻块动画让位、Esc 取消、单步撤销），点击六点手柄打开块菜单；列表项可独立操作，多块可以整体拖动、转换和复制，列表项可跨列表移动、拖出列表或向右拖入其他列表项，落点显示蓝色指示线。手机提供当前位置插入、块菜单、缩进和撤销工具。
- 数据库的文本、数字、单选、多选、状态、日期与时间范围、复选框、链接、公式、创建及更新时间属性。选项弹层可直接输入并创建新选项；日期单元格使用月历弹层选择单个日期或范围，并可选时间，手机使用底部月历面板。
- 数字格式、小数位、人民币、百分比；列汇总支持求和、平均、最小、最大、计数与非空计数。汇总范围是当前筛选后的全部记录，分组另有组内汇总。
- 多条件筛选、多列排序、分组、保存多个视图、表格及列表视图、列隐藏、列宽及列排序。
- 每条记录有独立正文。桌面内联编辑与 Enter / Tab 切换，手机使用单元格底部面板和全屏记录详情。
- CSV 导入字段映射、导入前整批校验、CSV 导出、Excel 多行多列粘贴确认。
- 完整 JSON 备份与恢复；自动保存、错误反馈、本机未保存内容恢复副本、并发写入冲突检测。
- 内置笔记、项目任务、阅读清单示例；新建数据库可选任务、账本及阅读模板。

## 公式

使用 `{属性名}` 引用同一条记录的其他属性，例如：

```text
{数量} * {单价}
ROUND({数量} * {单价}, 2)
IF({总数} = 0, 0, {已完成} / {总数})
SUM({收入}, -{支出})
```

支持 `+ - * / %`、括号、比较运算、`ROUND`、`SUM`、`MIN`、`MAX`、`ABS` 和 `IF`。公式由独立解析器计算，不执行 JavaScript。小数计算使用 Decimal.js；空数字按 0 计算，除零、非数字引用和循环引用会显示错误。`IF` 仅计算命中的分支。

## 数据与部署配置

| 环境变量        | 默认值                | 用途                              |
| --------------- | --------------------- | --------------------------------- |
| `HOST` | `0.0.0.0` | 监听地址；线上设为 127.0.0.1 |
| `PORT`          | `5173`                | HTTP 端口                         |
| `DATABASE_PATH` | `data/notionx.sqlite` | SQLite 数据文件                   |
| `APP_PASSWORD`  | 未设置                | 设置后开启单用户密码登录          |
| `COOKIE_SECURE` | `false`               | HTTPS 部署设为 `true`             |
| `NODE_ENV`      | 开发模式              | `production` 使用已构建的静态文件 |

SQLite 启用 WAL 和事务，页面、数据库、属性、记录、视图分别存表，动态内容使用 JSON 保存。普通编辑只更新变更实体，完整恢复在事务中替换。数据库结构版本记录在 metadata，当前为版本 1。

建议通过“设置与备份”定期导出 JSON；运行中的 SQLite 数据库不应只复制 `.sqlite` 文件而忽略 WAL。图片作为正文内的 data URL 保存在数据库，单张限制 5MB。

目前通过工作空间版本号防止旧设备覆盖新内容。其他窗口或设备更新后，空闲窗口每 15 秒获取一次新版本；并发冲突时保留本机修改，提示导出及重新加载。当前不支持离线编辑合并、实时多人协作、跨数据库关联与 rollup。所有记录加载到浏览器，适合个人中小规模数据，尚未对数十万记录做虚拟化及服务端分页。

## 技术栈

React、TypeScript、Vite、Radix UI 组件原语、自定义响应式样式、TanStack Table、Tiptap、DayPicker、date-fns、Express、better-sqlite3、Decimal.js。DayPicker 按需加载，不进入首屏主包。

## 验证

```sh
npm test
npm run build
```

浏览器测试使用已安装的 Google Chrome，先启动应用，再执行：

```sh
TEST_URL=http://localhost:5198 npm run test:e2e
```

建议使用单独的测试数据库和端口，例如 `PORT=5198 DATABASE_PATH=data/browser-test.sqlite npm start`。测试创建并清理自己的数据；完整备份恢复测试请勿针对正在使用的个人工作空间运行。

交互说明：页面标题会随内容自动换行，在标题中按 Enter 或点击正文下方空白处会把光标移到正文末尾；新建页面后可直接输入标题。文本格式工具栏只在选中文字时出现，定位在选区上方；折叠光标时不显示，离开编辑器或取消选择后收起。块类型转换、块操作和撤销/重做位于左侧手柄菜单，手柄从正文或左侧空白 gutter 进入都会出现。所有表单下拉框使用 Radix Select，支持键盘选择与 Escape 关闭。数据库单选、多选和状态使用可搜索弹层，可直接创建新选项；多选可以连续勾选后点击“完成”。日期使用 DayPicker 月历，支持范围、月份切换、今天/明天/下周快捷选择和可选时间。单元格 Enter 保存并沿同列向下编辑（跳过公式等只读列），Tab 跳过计算列，Escape 放弃草稿；无效数字显示错误提示。列宽支持实时拖动、键盘左右调整、双击重置。数据库行、列拖动展示完整内容（列包含汇总），相邻内容平滑让位，支持边缘自动滚动、Esc 取消和落位动画；松开后保存顺序，标题列固定。启用排序或分组时暂停手动拖动记录。手机端可通过“属性”入口找回隐藏列。


### 编辑交互与撤销

- 普通文字拖选和整块选区分开：在文字内部跨段拖动只选中文字，左侧空白处拖动选块；块选中后 Enter 返回编辑，不删除内容。Esc 切换块选择，Shift+方向键可扩大或收缩；Ctrl/Cmd+Shift+上下键移动所选块，Ctrl/Cmd+/ 打开块菜单。
- 代码块中的斜杠保持为代码；Esc 关闭命令菜单后，同一个触发符不会在后续输入时重新弹出。选中文字后 Ctrl/Cmd+K 打开链接编辑，其他位置仍打开全局搜索。
- 普通表格工具浮动在表格附近，离开编辑器或表格滚出可见区域后收起，提供前后插行列、表头切换、合并拆分与删除操作。
- 数据库支持方向键单元格导航、Shift 扩展矩形选区、拖动区域选择、区域复制和批量清空；计算列保持只读。单击单元格进入选中状态，双击、Enter 或 F2 进入编辑，直接输入会以输入内容开始编辑；选中区域右下角的下拉填充柄可向下复制源区域的值，公式、创建及更新时间等只读属性会自动跳过，整次填充可撤销；分组视图下暂不提供填充。分组后按屏幕中的行顺序导航并跳过折叠组。属性输入的 Tab/Enter 在表格和记录详情中分别导航，Escape 取消后立即恢复单元格焦点。
- 每个数据库保留最多 80 步本次会话操作历史，提供撤销/重做按钮；单元格焦点下可用 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z。正文编辑保留独立撤销历史。刷新、重新载入或收到其他设备的新版本后数据库历史清空；撤销属性操作不会覆盖后续正文编辑。
- 日期面板定位到已选日期，支持年月下拉和直接输入日期。新插入的工作空间页面引用按页面 ID 显示当前名称；历史普通链接保持原文字。
- 手机编辑工具根据 visualViewport 调整位置；桌面浏览器的手机模拟不等同于 iOS/Android 真机键盘验证。


### 阿里云部署

线上地址：https://notionx.mushayu.com 。使用与本机 PromptX 相同的阿里云主机。应用独立运行于 notionx.service，监听 127.0.0.1:3220，由 /usr/local/nginx 反向代理并使用 Let's Encrypt HTTPS。证书由服务器现有 certbot timer 自动续期。

本地执行 bash scripts/deploy-aliyun.sh 运行测试、构建、上传并准备发布。随后在 PromptX 托管终端中前台执行 bash scripts/run-aliyun.sh，激活服务并持续显示远端日志，同时建立本机 127.0.0.1:53220 的 SSH 就绪检查隧道。应用本身由远端 systemd 托管，关闭本机日志终端不会停止线上应用。

首次发布自动生成访问密码，保存在服务器 /etc/notionx/notionx.env；部署脚本会同步到本地 .env.aliyun（权限 600，Git 忽略）。使用其中 APP_PASSWORD 的值登录。更改服务器该文件后重启 notionx.service 生效；重启后需要重新登录。

- 发布目录：/opt/notionx/releases/，current 指向当前版本，previous 指向上一版；每次发布保留旧版本，回滚时将 current 切回 previous 指向的绝对路径并重启服务。
- 持久化数据：/var/lib/notionx/notionx.sqlite，以独立 notionx 用户运行；重新部署不覆盖数据库。不上传本地 data/，本地已有内容可用应用的 JSON 导出、导入迁移。
- 自动备份：notionx-backup.timer 每天北京时间 04:20 执行 SQLite 在线一致性备份，保留最新 14 份于 /var/lib/notionx/backups/。发布前和首次启动也会备份。备份仍在同一台服务器，请定期下载或另存至其他存储。
- 日志：ssh root@8.130.37.52 journalctl -u notionx.service -n 80 --no-pager。
- 手动备份：ssh root@8.130.37.52 systemctl start notionx-backup.service。
